# VIC BPO UI exposure (Task 5)

Generated: 2026-08-05T20:20:06Z.

## Decision: wired into the existing GFS/jurisdiction explorer, as a fourth toggle

Same reasoning as VIC AFS: this family is 11 measures, one financial
year, one department, one acquired edition - no monthly cadence and no
new dedicated page needed. `src/frontend/app/explorers/gfs/page.tsx`
already had exactly the right shape after Task 5 of the prior VIC AFS
milestone; added a fourth `"VIC BPO"` toggle option alongside Expenses/
Liabilities/VIC AFS.

## Backend: mirrors vic_afs.py's API exactly

`src/backend/routers/v2/vic_bpo.py` - `/v2/vic-bpo/measures` (11
measures + metadata) and `/v2/vic-bpo/series?measure_type=...` (both
`estimate_status` facts + citations for one measure). Config path
resolution follows the same multi-candidate `compatibility.py`/`mfs.py`/
`vic_afs.py` pattern, applied correctly from the start.

## UI capabilities present

| requirement | implementation |
|---|---|
| measure selector | dropdown populated from `/v2/vic-bpo/measures` |
| year | fixed at FY2024-25 (the source's only year - an actual-vs-budget comparison, not a multi-year series) |
| vintage selector | **genuinely different from VIC AFS**: here "vintage" is the actual-vs-budget dimension itself, not a time-based edition. Both `estimate_status` values are always shown side by side, each row explicitly labelled "Actual —"/"Budget —", plus a badge stating "Vintage: actual vs budget, FY2024-25 (both shown below)" |
| flow/stock indicator | a badge that switches live between "Flow (financial year)" and "Stock (point-in-time)" when the measure selector changes |
| period disclosure | each row explicitly states "(as at <period_end>)" |
| citation access | clicking a row populates a citation box (locator + cached copy path) - reused the same `SimpleCitationBox` component built for VIC AFS (renamed from `VicAfsCitationBox` since it's now shared by both families) |

Never inserted into any additive annual tree - the existing `expenses`/
`liabilities`/`vic_afs` toggle options are untouched.
